# CherryBot — Apology for Cherry

This repo contains a playful, tech-themed apology for Cherry from vansh.

Files added:

- apology_for_cherry_interactive.sh — A terminal interactive apology script you can run locally.
- apology_web/ — A small GitHub Pages-friendly webpage with animated 🍒 and 💖 emojis in the background and interactive forgiveness buttons.

To run the script locally:

```bash
chmod +x apology_for_cherry_interactive.sh
./apology_for_cherry_interactive.sh
```

To view the webpage locally:

Open `apology_web/index.html` in your browser.

To host on GitHub Pages:

- In your repo settings, enable GitHub Pages from the `main` branch (root). The page will be available at `https://<your-username>.github.io/Sorry-/` after a few minutes.
